Game data in OPFS

Copy a folder (a mounted CD, a game's data directory) into this site's private storage once. Games then read it on demand in a Worker, with no preloading and no prompt on later visits. Copying uses csfs; gasm only reads.

Run a game against a folder: index.html?game=<game>.wasm&opfs=gasm-assets/<name>&autostart (Worker mode is implied).
